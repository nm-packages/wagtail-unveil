How It Works

This report is generated by walking Django's URL resolver to discover all admin/ routes. Each URL pattern is inspected for parameters (<pk>, <int:pk>, etc.) and classified as static or parameterized. Parameterized snippet URLs are resolved using real database instances so they can be tested too. POST-only endpoints and regex-based patterns are detected and marked as non-testable. Testing sends a browser-side fetch() GET request using your current session.
