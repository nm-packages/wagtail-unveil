How It Works

This report combines two sources of frontend URLs: Page URLs discovered from live Wagtail pages via Page.objects.live().specific(), and Resolver URLs discovered by walking Django's URL resolver for non-admin routes. Page URLs are concrete paths derived from the page tree. Resolver URLs with parameters are marked as non-testable. Testing sends a browser-side fetch() GET request using your current session.

Columns

Testing

Test
Sends a GET request and shows the HTTP status code.
Test All
Runs through all visible testable URLs sequentially.
Hide / Show Untestable
Toggles visibility of rows that can't be tested (parameterized, regex). Preference is saved in a cookie.
Pause / Continue / Cancel
Controls for the Test All run. Failed URLs move to the top.

Status Codes

2xx (green)
Success — the URL responded normally.
3xx (amber)
Redirect — the URL redirects elsewhere.
4xx / 5xx (red)
Error — client or server error.
